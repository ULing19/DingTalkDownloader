# 直播分享短链与观看密码（测试版）

适用版本：`1.3.10`。已使用两条真实带密码分享完成二维码识别、官方密码验证和完整回放下载；其它分享仍受链接有效期、观看范围和媒体格式限制。

## 使用步骤

1. 公开直播分享可直接导入并验证观看密码；群回放、闪记、群文件仍需通过软件的“重新登录”完成钉钉授权。
2. 将分享者提供的 `https://live.dingtalk.com/r/…` 链接粘贴到左侧；也可用“导入二维码”选择分享图片。
3. 点击“解析到任务列表”，确认对应任务显示“直播分享”，勾选需要下载的项目。
4. 点击“开始下载”。软件会展开短链并请求钉钉的官方验证接口；只有接口要求观看密码时才弹出输入框。
5. 输入分享者提供的 **6 位观看密码**，点击“验证并继续”。密码错误会明确提示，本次任务最多提交三次；取消只取消当前任务，其余任务继续。
6. 等待下载结束，到保存目录核对视频标题和内容。不同任务同名时自动增加编号。

密码只用于本次任务内的官方验证，不加入链接、不写入配置和任务文件、不传给外部下载程序、不记录到软件日志。二维码文件、观看密码和完整分享后缀不应贴到公开 Issues。

## 支持边界和错误说明

| 提示 | 处理方法 |
| --- | --- |
| 需要观看密码 / 密码错误 | 向分享者核对密码；与钉钉扫码登录是两件事，无需反复重新登录 |
| 没有观看权限 | 使用获得授权的账号，或请分享者调整观看范围 |
| 链接失效、回放删除或下架 | 请分享者确认回放状态并重新分享 |
| 未结束或不完整的播放列表 | 不会将其标记为完整视频，待回放处理结束后重试 |
| 独立音轨或不支持的分段格式 | 当前测试版会明确停止，不会仅保存视频而丢掉声音 |
| 网络错误 | 检查网络后重试，不会因此循环要求登录 |

登录后使用官方 `getLiveRoomInfo` 接口；本机会话失效或没有登录时，公开分享使用官方 `getLiveRoomPublicInfo` 接口继续验证观看密码，不反复要求扫码。当前账号明确收到观看权限拒绝时，会保留该错误。官方返回的旧式 HTTP 回放地址会以相同主机、路径和签名升级到 HTTPS 请求。

软件只使用通过验证后返回的回放地址，不猜测密码或绕过观看权限。播放列表需有结束标记，合并后的时长需与列表一致。音视频轨检查只能发现部分异常，不能代替对实际画面与声音的人工核对。
