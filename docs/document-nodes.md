# 钉钉文档与原文件下载（1.3.26）

支持识别 `https://alidocs.dingtalk.com/i/nodes/节点标识`，沿用现有的输入框、任务选择、开始下载和停止按钮。

## alidocs 原文件预览（与 QR 共用下载流程）

`https://alidocs.dingtalk.com/uni-preview?spaceId=…&fileId=…` 属于钉盘文件预览地址，直接归为“群文件”，复用 QR 的登录会话和 MediaGo 原文件下载后端，不需要先转成在线文档正文。也接受 `cloudSpaceSpaceId` / `cloudSpaceDentryId` 参数；同一个链接内的两组标识必须一致。

解析时保留文件访问上下文中的 `dentryUuid`、版本号、场景、文件扩展名等已知参数，去掉来源追踪字段。Excel、Word、PDF 等下载成功后保留原始扩展名和文件字节，不经过视频转换。链接被识别不等于当前账号已获文件访问权；浏览器与下载器登录账号不同时，仍需在下载器中用可访问该文件的账号重新登录。

验证范围：URL 识别、别名冲突校验、传递给 QR 后端的上下文、文件下载字节及扩展名有自动测试。2026-10-27 已用更新后的本机 64 位软件成功下载一份 `uni-preview` Excel 原文件，大小 14,370 字节，与链接的文件大小一致；XLSX ZIP/CRC、工作簿及工作表 XML 校验通过。此前使用旧的下载器登录态时文件接口返回 `13020005`，在软件内重新登录后成功。因此浏览器能预览但软件下载失败时，应先确认软件登录的账号及访问范围。此结果仅覆盖已测文件，不代表所有链接和组织策略都适用。

维护诊断可用 `DingTalkDownloader.exe --verify-file-download 任务配置文件` 执行一次真实群文件任务。配置包含 `url`、绝对路径 `save_dir` 和尚不存在的绝对路径 `report`。该入口仍会校验既有订单授权、钉钉登录态及下载引擎，并通过正常下载工作线程执行。报告不包含链接、Cookie 或订单号；下载后的 Office 文件会检查 ZIP 容器。不会自动激活新订单、清除授权或替换登录账号。

## 文档节点正文（实验功能）

1. 粘贴完整链接，点击“解析到任务列表”，任务类型显示“文档”。
2. 选择保存目录，点击“开始下载”，使用有效的订单授权。
3. 软件打开独立 Edge / Chromium 窗口。请在这个窗口使用有权访问该文档的钉钉账号扫码登录；登录后自动继续。该窗口与日常浏览器及群直播登录窗口相互隔离。
4. 解析器读取节点元数据，提取 `spaceId` 与文件标识，转换为和 `qr.dingtalk.com` 群文件相同的预览链接，复用群文件引擎获取原文件；成功时保留原始扩展名。
5. 如果是原生在线文字文档，解析器也会从顶部滚动到末尾，按稳定段落标识合并当前页面已渲染的文字。原文件未取得时会将文字另存为 UTF-8 `.txt`，任务标为“需检查”并明确提示“非原始文件”。

原文件获取仍取决于钉钉返回的文件信息、账号访问权限和网络状态。节点拥有 `spaceId` / 文件标识不保证一定存在可下载的 Word/PDF 原文件。实验功能不会调用导出接口、修改文档权限、读取隐藏的编辑器数据或把提取文字伪装成原文件。

文本结果仅包含正文段落，不包含目录、账号信息、聊天记录、评论区和点赞按钮。标题中的不可见控制字符会清理，同名输出自动编号。图片、附件、画布及复杂表格无法以正文文本完整保留，遇到这些内容会提示或停止提取；图片和版式需要原文件。

关闭或停止任务后清理本次临时浏览器。文档任务串行读取，同批其他下载任务仍遵循原来的并发设置。文档登录会话只在本批临时窗口中使用，不覆盖已保存的群直播账号。

验证范围：文档节点识别、已登录页面的元数据映射及长文档正文滚动提取已实测。`uni-preview` 原始 Excel 下载已验证成功，见上节；`/i/nodes/…` 原生在线文字文档与表格、画布的原件输出仍需分别验证，不将其视为所有钉钉文档类型均已支持。
