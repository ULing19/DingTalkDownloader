# 1.3.11 登录校验网络修复

修复部分电脑已完成授权后提示“无法连接钉钉登录校验接口”的问题。

- 固定钉钉登录校验接口使用经过证书验证的 TLS 直连，不读取系统 HTTP(S) 代理。
- 直连仍验证 TLS 证书及主机名，不修改系统代理或全局环境变量。
- 保留账号被拒绝、会话过期的正常处理；不会将网络成功等同于授权成功。
- 对 DNS、连接超时、连接拒绝、代理和证书错误提供脱敏后的提示。
- 同一连接方法用于登录校验、群回放列表和登录后的密码分享验证。

使用方式：安装修复版，或将绿色版完整解压到新目录。选择与系统一致的 x64 或 x86 包；无需先清除 Cookie。重新点击“开始下载”，只有明确提示登录过期时才重新扫码。

验证：在代理指向本机未开放端口的情况下，旧版连接被拒绝，修复版直连后获得钉钉接受当前会话的响应。客户截图本身不能证明所有同类报错都来自相同原因；仍失败时，请提供修复版显示的具体错误类型，切勿发送 Cookie。

32 位实验包包含完整 x86 引擎，本轮验证在 64 位 Windows 的 32 位兼容环境完成；未声称已在真实 32 位系统上验证所有功能。
