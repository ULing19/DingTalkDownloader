================================================================================
                         钉钉回放下载器 1.3.9
                              使用说明
================================================================================

一、软件简介
--------------------------------------------------------------------------------
本工具为 Windows 图形界面程序，用于整理和下载你有权限访问的钉钉媒体内容。
它组合使用 MediaGo 与 GoDingtalk 两个开源命令行引擎，并使用 FFmpeg 合并视频。
群回放优先保留完整 HLS 时间轴，GoDingtalk 仅在主链路不可用时兼容回退。

项目开源地址：
  https://github.com/ULing19/DingTalkDownloader

上游引用：
  GoDingtalk   https://github.com/NAXG/GoDingtalk
  MediaGo      https://github.com/Sophomoresty/mediago （v0.3.0，Unlicense）

本软件不是钉钉官方工具，不会提升账号权限，也不提供代登录服务。


二、支持的链接
--------------------------------------------------------------------------------
【群直播回放】
  https://n.dingtalk.com/dingding/live-room/index.html?roomId=...&liveUuid=...

【钉钉闪记】
  https://shanji.dingtalk.com/app/transcribes/<转写ID>
  例如：
  https://shanji.dingtalk.com/app/transcribes/example_transcribe_id_2026

【群文件/钉盘视频】
  https://qr.dingtalk.com/page/yunpan?route=previewDentry&spaceId=<空间ID>&fileId=<文件ID>&type=file
  其中 spaceId 和 fileId 是云盘对象标识，不能改写成 roomId/liveUuid。

群文件视频会走播放流；普通 PDF、Office、图片或压缩包在解析器返回直接下载地址时，
会按 MIME、文件名或 URL 扩展名原样保存，不经过 FFmpeg。只有预览地址、文件夹、
权限不足或没有直接下载地址的条目会提示没有可下载媒体；并非所有文件类型都得到平台保证。

【已打开群回放链接一键获取】
  主程序已经内置“一键获取已打开群回放”，不需要另外启动客户资料目录中的 EXE，也不依赖已记忆群映射。
  1. 在钉钉登录并打开需要处理的群“直播广场”；多个群可分别打开直播页。
  2. 回到本软件，点击输入区下方的“一键获取已打开群回放”。程序会通过登录态只读接口自动读取每个群的全部分页，不需要手动滚动列表。
  3. 选择一次保存根目录，程序会按已识别的群名称建立文件夹，并写入各自的：
       链接集.txt
  4. 链接会同时加入输入框和任务列表，并保留钉钉回放标题用于最终文件命名。
     标题映射以 URL 的 SHA-256 哈希为键保存在本机应用数据中，重启后重新导入链接仍会恢复群名与原标题。

  保存位置必须是用户选择的已有可写文件夹。页面不是直播广场、列表仍在加载、
  文件夹不可写或无法确认群身份时会提示失败，且不会覆盖原有链接集.txt。
  程序会一次处理所有已打开的群直播页；未打开直播页的群无法凭空读取，程序不会枚举或自动打开账号全部群，也不会自动点击群聊。
  该功能从 CEF 日志识别群 ID，优先调用登录态下的只读回放列表 RPC 自动翻页；
  RPC 不可用时才回退读取经过严格校验的渲染进程内存。全程不发送消息或执行写操作。


三、安装与启动
--------------------------------------------------------------------------------
【安装版（推荐）】
  1. 从 GitHub Releases 下载 DingTalkDownloader_1.3.9_Setup.exe。
  2. 双击安装程序，按向导选择目录。
  3. “创建桌面快捷方式”默认勾选，可按需要取消。
  4. 从开始菜单或桌面快捷方式启动。

  安装包已经包含 GUI、GoDingtalk、MediaGo、FFmpeg 和说明文件。

【绿色版】
  1. 下载 DingTalkDownloader_1.3.9_Portable.zip。
  2. 解压到任意目录后，双击 DingTalkDownloader.exe。
  3. 不要拆散以下文件：
       DingTalkDownloader.exe
       GoDingtalk_v2.5.2_windows_amd64.exe
       mediago.exe
       ffmpeg.exe
       .goDingtalkConfig\config.json
       .goDingtalkConfig\cookies.json

  绿色版不写入安装项；退出程序后可删除整个解压目录。
  删除前请备份 video\ 中仍需保留的数据；登录状态保存在当前 Windows 用户目录。

Windows SmartScreen 可能提示“未知发布者”。请只从本项目 Release 下载，
并按 Release 页面提供的 SHA-256 校验文件；不要运行来源不明的替换引擎。


四、首次使用与登录
--------------------------------------------------------------------------------
  1. 启动程序，点击“重新登录”。程序优先自动使用 Windows 自带的 Microsoft Edge，
     不要求安装 Google Chrome。
  2. 若未找到 Edge，程序会继续寻找 Chrome，并尝试发现 Brave、Chromium、
     Vivaldi、Opera、360、QQ 等 Chromium 内核浏览器；第三方浏览器是否可登录
     取决于具体版本的 Chromium 调试接口兼容性。仍未找到时按提示手动选择浏览器程序。
  3. 使用有权限观看目标回放、闪记或群文件视频的钉钉账号完成授权。
  4. 授权后等待浏览器窗口和登录引擎自动结束。软件校验会话并提示“登录成功”后，
     才会启用下载；若登录由“开始下载”触发，成功后会自动继续刚才的任务。

首次运行不需要预先准备 Cookie。软件会先在可写的用户目录创建合法的空
config.json 和 cookies.json，授权成功后再原子写入实际会话。登录窗口由软件使用
独立临时浏览器配置直接打开钉钉授权页；不要连续点击“重新登录”，也不要手动复制
浏览器 Cookie。其它 Edge、Chrome 等浏览器无需关闭，只需在软件唤起的独立窗口中授权。
若记忆的浏览器无法打开授权页或持续停在 about:blank，软件最多会自动换一个已安装的
Chromium 浏览器重试一次，不会循环打开窗口。请退出旧版下载器并升级到 1.3.8。

Firefox、Safari 和 Internet Explorer 不提供本登录引擎所需的 Chromium 调试接口，
不能用于自动登录。登录窗口使用独立会话，不会直接导入日常浏览器 Cookie；完成登录后，
解析和下载不依赖浏览器持续运行。

登录会话保存在当前 Windows 用户可写且跨版本稳定的目录：
  %LOCALAPPDATA%\DingTalkDownloader\.goDingtalkConfig\

1.3.9 的程序目录会附带内容为 {} 的兼容配置占位文件，但真实登录态仍只写入
当前 Windows 用户目录，不会打进绿色包。首次运行时，如果程序目录中存在旧版
`.goDingtalkConfig\` 且新目录还没有
对应文件，软件会复制旧配置和会话；旧文件不会被删除或覆盖。登录与下载始终使用
同一份 config.json、cookies.json 和已经选择的 Chromium 浏览器路径。

会话可能因过期、退出登录、设备变化或权限变化而失效。此时再次点击
“重新登录”即可。不要把 cookies.json、浏览器 Cookie 导出文件或密码发给任何人。


五、添加任务
--------------------------------------------------------------------------------
【粘贴链接】
  在左侧输入框粘贴完整 URL，每行一个。以 # 开头的行会被忽略。

【导入文本】
  点击“导入文本”，选择 .txt 文件。格式与粘贴相同，可以混合三类链接。

【导入二维码】
  点击“导入二维码”，可多选 PNG/JPG/BMP/WebP 图片。建议使用原始清晰图，
  保留二维码四周空白；识别失败时直接粘贴二维码打开后的完整 URL。

点击“解析到任务列表”后，先核对链接类型和群内原标题。每条任务前的复选框默认勾选；取消不需要的项目，或先点“全不选”再勾选指定视频，最后点击“开始下载”。


六、保存目录与输出
--------------------------------------------------------------------------------
默认保存目录：
  video\

可在界面中选择其他目录，也可按科目建立子目录，例如：
  video\数学-基础\
  video\英语-强化\

群直播回放优先由 GoDingtalk 取得完整分片，再由引擎合并成 MP4；单个回放使用保守并发、120 秒 HTTP 超时，并在网络抖动时自动重试；MediaGo 作为兼容回退。
主链路不可用时才回退到 GoDingtalk。FFmpeg 会生成缺失的 PTS、选择首个
音视频轨并归零负时间戳，不重新编码画面。
闪记和钉盘视频按源媒体返回的播放结果下载；钉盘普通文件若有直接下载地址，
按原始扩展名保存，不调用 FFmpeg。不同链接即使标题相同，也会自动追加 `(1)`、
`(2)` 等编号保存，不会只保留一个文件。不是每条闪记都含有视频画面。

下载状态可能显示：等待中 / 下载中 / 转换中 / 完成 / 需检查 / 失败 / 已取消。
下载过程中不要移动或删除程序目录；可点击“停止”取消后续任务。

MP4 完成后会检查音视频轨起止时间。如果提示“视频轨比音频早结束”或任务显示
“需检查”，文件仍会保留，请先用原回放链接重试。程序不会用 -shortest 静默删除较长音频；
若源回放本身缺少后段视频分片，重新封装也不能生成不存在的画面。


七、卸载与数据保留
--------------------------------------------------------------------------------
【安装版】
  可从 Windows“设置 → 应用”、开始菜单中的卸载项，或安装目录中的卸载程序
  卸载。卸载程序始终保留安装目录中的 video\ 和旧版 .goDingtalkConfig\，
  这样不会误删视频；新版登录会话仍保存在：
    %LOCALAPPDATA%\DingTalkDownloader\.goDingtalkConfig\
  确认不再需要登录状态时，再手动删除 `%LOCALAPPDATA%\DingTalkDownloader`。
  卸载时会同时删除 %LOCALAPPDATA%\DingTalkReplayLinkCollector 中的标题映射和保存目录记录。

【绿色版】
  退出程序后删除整个解压文件夹即可；删除前请先备份用户数据。
  如需完全清理，再删除 %LOCALAPPDATA%\DingTalkDownloader 和
  %LOCALAPPDATA%\DingTalkReplayLinkCollector。


八、常见问题
--------------------------------------------------------------------------------
Q1：提示“未找到下载引擎”怎么办？
A1：确认 DingTalkDownloader.exe、GoDingtalk_v2.5.2_windows_amd64.exe、
    mediago.exe、ffmpeg.exe 在同一目录，且没有被杀毒软件隔离。

Q1.1：没有安装 Google Chrome，能否登录？
A1.1：可以。1.3.9 会优先自动使用 Windows 自带的 Microsoft Edge，并兼容 Chrome。
      其他 Chromium 内核浏览器会自动发现并尝试，但结果取决于具体版本。
      自动检测不到时，按提示选择浏览器的 .exe 文件即可。
      Firefox 不能用于自动登录，但完成有效登录后的下载阶段不依赖浏览器。

Q2：提示“缺少 roomId 或 liveUuid 参数”怎么办？
     A2：这是直播解析器收到闪记或群文件链接的表现。升级到 1.3.3，粘贴完整的
    shanji 或 qr.dingtalk.com URL，不要手工拼接 roomId/liveUuid。

Q3：闪记提示缺少 account/access_token 或 deviceid？
A3：登录会话不完整或已过期。1.3.9 会在下载前检查必要字段，并通过钉钉只读
    注册接口确认会话是否被接受；该检查不读取群数据，也不代表拥有某个群的权限。
    只有钉钉明确拒绝会话时才会要求重新登录，网络异常只会提示稍后重试；
    点击“重新登录”，通过软件唤起浏览器并等待软件提示登录成功。没有权限时程序不会绕过登录。

Q4：群文件提示“不支持 URL”？
A4：旧版引擎可能没有注册 qr.dingtalk.com/page/yunpan 入口。确认 GUI 和
     mediago.exe 均为 1.3.9 发布包中的版本，并保留 route、spaceId、fileId、type 参数。

Q5：群文件提示“没有可下载媒体”？
A5：先用同一钉钉账号在客户端打开原链接。若客户端提示无权访问，请让文件所有者或群管理员授权，
    程序不会绕过权限；若能预览，再检查视频是否完成转码，或普通文件是否提供直接下载地址。
    只有预览地址、没有直接下载地址的条目或文件夹仍可能无法保存。

Q6：只有 TS，没有 MP4？
A6：确认同目录有 ffmpeg.exe，且未被安全软件拦截；然后重试失败任务。

Q7：二维码识别失败？
A7：使用更清晰的原图，放大并保留二维码边缘，或直接复制二维码解析出的 URL。

Q8：点击“一键获取已打开群回放”失败？
A8：确认钉钉已登录、目标群“直播广场”仍保持打开，并确认保存根目录存在且可写。
    新版会自动读取全部分页，不需要滚动到末页。失败不会覆盖旧文件。

Q9：提示“视频轨比音频早结束”怎么办？
A9：请使用 1.3.3 或更高版本重新下载；新版会保留钉钉源 PTS，修复稀疏屏幕共享帧
    被 FFmpeg 压缩时间轴的问题。若仍提示且钉钉也定格，通常是源回放本身不完整。

Q10：如何查看问题信息？
A10：提交问题前请保留 GUI 日志中的错误类型和版本号，并删除 URL 中的私密参数、
    Cookie、账号名和文件名，再到：
    https://github.com/ULing19/DingTalkDownloader/issues
