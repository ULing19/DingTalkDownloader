## 钉钉回放下载器 1.3.25（需订单授权）

- 修复一键获取群回放后保存配置或链接文件时出现的 `OSError` / `WinError 17`：兼容 Windows 用户目录重定向及目录联接，避免表面同目录的替换操作被误判为跨磁盘移动。
- 临时文件和目标文件统一使用真实父目录，继续原子保存；替换失败时保留原文件，不采用复制后删除的降级方案。
- 保存失败时显示具体阶段和系统错误码，并区分权限不足、空间不足等情况；错误提示不输出私人路径、回放链接或 Cookie。
- 64 位及 32 位安装版、绿色版均包含此次修复，保留 1.3.24 的回放名称校验、同名文件编号、序号和日期勾选功能，不增加按钮。
- 修正 32 位版本只读内存回退采集的结构布局及大地址范围，避免因为字段偏移错误而读不到已加载的回放数据。
- 正常覆盖升级即可，无须先卸载或清除授权。授权站点仍仅使用 license.uling19.com，升级保留本机授权、钉钉登录会话及已有视频。

安装版和绿色版二选一；32 位仍为实验版，尚未在原生 32 位 Windows 系统上完成全链路实测。

验证：发布范围 296 项测试通过（另含 72 个子测试）；32 位解释器下 163 项定向测试通过，包括真实测试子进程的只读内存采集。采集保存修复已在实际重定向用户目录完成首次保存及覆盖保存测试；本机图形界面已成功采集、保存并生成 168 条不重复回放任务。本次验证未开始批量下载。
