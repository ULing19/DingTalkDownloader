# 闲鱼订单授权服务

此服务把下载器兑换码关联到一个订单，并按订单最多绑定两台设备。闲鱼订单目前由卖家在闲鱼管理后台人工核验后录入；在没有闲鱼官方开放平台授权和订单接口凭据前，不能将用户填写的订单号当成“已付款”的证据。

## 当前实现

- SQLite 保存订单号 HMAC 摘要、订单尾号掩码、兑换码 HMAC 摘要、设备哈希和必要审计事件，不保存明文订单号或兑换码。
- 管理页面 `/admin` 支持创建（自定义或随机码）、撤销/恢复、删除、修改订单/兑换码/有效期、清空设备绑定。管理 API 使用环境变量 Bearer token；兑换码只在创建成功时返回一次。
- 同订单不同兑换码也共用同一个两设备额度；相同设备重复激活幂等。
- 桌面端把兑换信息用 Windows 当前用户 DPAPI 加密保存在 `%LOCALAPPDATA%\DingTalkDownloader\license.dat`，下载开始前通过 HTTPS 在线校验。服务不可用时采用 fail-closed：本次下载不开始。
- 正式部署可通过 `XIANYU_ITEM_IDS` 配置下载器商品 ID，授权服务从同机闲鱼后台数据库只读同步已生成发货内容的订单；订单号本身作为兑换码。代下载商品不在配置中，因此不会被自动授权。

## 部署要求

生产环境必须使用由 Windows/macOS/Linux 系统信任、且 SAN 覆盖服务地址的 HTTPS 证书。客户端默认地址在 `license_client.py` 中；目前指向服务器 IP，因此证书必须包含该 IP 的 IP SAN，不能关闭证书校验。也可改为你控制的 HTTPS 域名。

1. 使用受支持的 Python 3 环境安装 `requirements.txt`。
2. 为 `LICENSE_ADMIN_TOKEN` 和 `LICENSE_CODE_PEPPER` 分别生成独立的高熵随机值（至少 32 字节），写入仅 root 可读的服务环境文件；不要提交真实值或放进客户端。
3. 将数据库目录设为仅服务账户可读写，并纳入加密备份。不要把 SQLite 数据库放在仓库目录。
4. 用 systemd 等进程管理器运行 Uvicorn，**只监听 `127.0.0.1`**；由已配置可信 TLS 证书的反向代理终止 HTTPS，并加请求体上限、连接/请求超时以及基于来源 IP 的速率限制。公网防火墙只开放需要的 HTTPS 端口；管理页建议再加来源 IP allowlist 或 VPN。
5. 验证 `/health`、管理端未认证拒绝、HTTPS 证书链、重启后 SQLite 数据保留，再把客户端 API 地址与实际证书主机名核对一致。

管理员可调用 `POST /admin/sync-orders` 触发一次幂等同步。服务只返回来源订单数量和新增数量，不返回订单号或发货内容。

## 运维注意

- 发布授权版之前，必须先完成服务部署、HTTPS 验证和 x64/x86 客户端打包验证。当前代码不包含管理员秘密，也不会自动尝试 SSH 部署。
- 服务器管理 token 泄漏后应立即换新并重启服务；Pepper 泄漏需按密钥轮换计划重置现有码摘要（旧兑换码将失效）。
- 删除记录会删除该订单的设备绑定；“重置设备”会释放此订单的两个激活名额。操作前请核对订单。
- 桌面应用的本地逻辑始终可能被有意修改；在线设备额度是服务端约束，不是无法绕过的 DRM。不要存放敏感内容或以此替代付款/订单核实。
