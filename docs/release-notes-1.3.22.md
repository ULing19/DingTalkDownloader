## 钉钉回放下载器 1.3.22（需订单授权）

- 修复已激活电脑在定期授权复查时出现 `last_online_at`、`server_expires_at` 的 `extra_forbidden` 错误。
- 本地校验时间和到期时间保留在本机，服务器请求只携带订单号、兑换码和设备标识。
